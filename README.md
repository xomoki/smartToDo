# SmartToDo

AI搭載型チーム生産性統合プラットフォーム

## 概要

SmartToDoは、既存ツール（Jira, Salesforce, Notion等）からタスクデータを吸い上げ、AIによる「標準化」「分析」「予測」を行い、統合ダッシュボードで可視化・フィードバックを行うSaaSプラットフォームです。

## 開発環境のセットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。
